# Анализ и прогнозирование оттока клиентов (Telco Customer Churn)

Данный проект посвящен комплексному анализу данных, кластеризации, обнаружению аномалий и построению моделей машинного обучения для прогнозирования оттока клиентов телекоммуникационной компании.

---

## Структура и этапы анализа

| Этап | Описание |
| :--- | :--- |
| **Предобработка данных** | Очистка от идентификаторов, обработка пропусков в `TotalCharges`, One-Hot кодирование категориальных признаков, масштабирование числовых признаков (`StandardScaler`). |
| **Разведочный анализ (EDA)** | Анализ распределения целевой переменной `Churn`, гистограммы числовых признаков, поиск выбросов (Boxplot) и корреляционная матрица. |
| **Необучаемое обучение (Unsupervised)** | Кластеризация методом k-средних (`KMeans`), метод локтя, снижение размерности (`PCA`) и поиск аномалий (`IsolationForest`). |
| **Классификация** | Обучение моделей: Logistic Regression, Decision Tree, Random Forest, Gradient Boosting. |
| **Оптимизация и балансировка** | Настройка гиперпараметров (`GridSearchCV`), сэмплирование методом `SMOTE` для устранения дисбаланса классов, ансамблирование (`VotingClassifier`). |
| **Интерпретация результатов** | Оценка метрик (Accuracy, Precision, Recall, F1, ROC-AUC), матрицы ошибок, ROC-кривые, важность признаков (Feature Importance) и SHAP-анализ. |

---

## Используемые библиотеки

* **Обработка данных и математика**: `pandas`, `numpy`
* **Визуализация**: `matplotlib`, `seaborn`
* **Машинное обучение**: `scikit-learn` (`LogisticRegression`, `DecisionTreeClassifier`, `RandomForestClassifier`, `GradientBoostingClassifier`, `VotingClassifier`, `KMeans`, `PCA`, `IsolationForest`, `GridSearchCV`)
* **Балансировка данных**: `imblearn` (`SMOTE`)
* **Интерпретация моделей**: `shap`

## Подробное описание этапов работы

### 1. Подготовка и предобработка данных
* Удаление неинформативного столбца `customerID`.
* Преобразование `TotalCharges` в числовой формат и удаление строк с пропусками.
* Бинарное кодирование целевого признака `Churn` (`Yes` -> 1, `No` -> 0).
* Преобразование категориальных признаков с помощью One-Hot Encoding (`pd.get_dummies`).
* Стандартизация числовых признаков (`tenure`, `MonthlyCharges`, `TotalCharges`) через `StandardScaler`.

### 2. Разведочный анализ данных (EDA)
* Оценка баланса классов целевой переменной `Churn`.
* Построение гистограмм распределения числовых показателей.
* Анализ выбросов для `MonthlyCharges` с помощью графика Boxplot.
* Построение тепловой карты корреляционной матрицы для оценки взаимосвязей между признаками.

### 3. Кластеризация и поиск аномалий
* **KMeans**: Определение оптимального количества кластеров методом локтя (Elbow Method) и сегментация клиентов по числу категорий.
* **PCA**: Понижение размерности признакового пространства до 2 компонент для двумерной визуализации классов оттока.
* **Isolation Forest**: Выявление аномальных наблюдений в выборке (`contamination=0.01`).

### 4. Обучение моделей классификации
Для прогнозирования оттока клиентов используются следующие алгоритмы:
* **Logistic Regression** (Логистическая регрессия)
* **Decision Tree** (Дерево решений)
* **Random Forest** (Случайный лес)
* **Gradient Boosting** (Градиентный бустинг)

Оценка производительности каждой модели осуществляется по метрикам: **Accuracy**, **Precision**, **Recall**, **F1-score**, **ROC-AUC**, а также с помощью **Confusion Matrix** и **ROC-кривой**.

### 5. Оптимизация, балансировка и интерпретируемость
* **GridSearchCV**: Подбор оптимальных гиперпараметров для модели градиентного бустинга (`n_estimators`, `learning_rate`, `max_depth`).
* **SMOTE**: Применение алгоритма оверсэмплинга для устранения дисбаланса классов при обучении.
* **VotingClassifier**: Создание взвешенного ансамбля моделей (Soft Voting) на основе логистической регрессии, случайного леса и градиентного бустинга.
* **Feature Importance & SHAP**: Визуализация важности признаков и детальный анализ их влияния на прогнозы с помощью SHAP-значений.
